Smart Stylist — Мультиязычный веб-ассистент капсульного гардероба
Smart Stylist — это веб-приложение на Python/Flask, которое подбирает одежду по текущей погоде и выбранному стилю. Проект объединяет моду и информационные технологии (FashionTech), помогая пользователям быстро собирать готовый образ на день.

📌 О проекте
Каждое утро многие люди задаются вопросом: «Что сегодня надеть?». Ошибка с выбором одежды может привести к дискомфорту: слишком лёгкая одежда — риск простудиться, слишком тёплая — перегрев. Современные приложения для гардероба часто требуют много времени (фотографирование вещей), платные или не поддерживают русский язык.

Smart Stylist решает эти проблемы:

Автоматически получает актуальную погоду для любого города через WeatherAPI.

Определяет одну из 5 погодных зон: freezing (≤0°C), cold (1–10°C), chilly (11–17°C), warm (18–23°C), hot (≥24°C).

Предлагает детальный список вещей для трёх стилей: casual, business, streetwear.

Поддерживает три языка интерфейса: русский, английский, французский.

Показывает тематические изображения с образами для каждого стиля и погодной зоны.

✨ Функционал
🌍 Погода в реальном времени — запрос к WeatherAPI по названию города.

🧥 Пять температурных категорий — от мороза до жары.

👔 Три стиля одежды — повседневный, деловой, уличный.

🌐 Мультиязычность — полная локализация интерфейса и рекомендаций на RU / EN / FR.

🖼️ Визуализация — две картинки с подобранным образом (слева и справа).

🛡️ Обработка ошибок — если город не найден или API недоступен, выводится понятное сообщение.

🛠️ Технологии
Python 3 — серверная логика.

Flask — веб-фреймворк.

Requests — HTTP-запросы к WeatherAPI.

HTML5 / CSS3 — вёрстка и адаптивный дизайн (трёхколоночная сетка).

Jinja2 — шаблонизация (встроена во Flask).

WeatherAPI — источник данных о погоде.

🚀 Установка и запуск
Клонируйте репозиторий:

bash
git clone https://github.com/ваш-username/smart-stylist.git
cd smart-stylist
Установите зависимости:

bash
pip install flask requests
Рекомендуется создать виртуальное окружение:

bash
python -m venv venv
source venv/bin/activate  # для Linux/macOS
venv\Scripts\activate     # для Windows
Настройте API-ключ (опционально):
В файле app.py уже указан демонстрационный ключ WeatherAPI. Для стабильной работы рекомендуется заменить его на свой, полученный после регистрации на weatherapi.com. Ключ хранится в переменной WEATHER_API_KEY.

Запустите приложение:

bash
python app.py
Откройте в браузере:

text
http://127.0.0.1:5000 
или же https://hurtfully-sterling-shrike.cloudpub.ru/
📖 Использование
Выберите язык интерфейса в выпадающем списке (переключение происходит автоматически).

Введите название города латиницей (например, Moscow, Paris, London).

Выберите желаемый стиль одежды.

Нажмите кнопку «Сформировать капсулу» (или аналог на выбранном языке).

Получите текущую температуру, описание погоды и подробный список рекомендованных вещей. По бокам отобразятся подобранные образы.

💡 Примечание: для корректного отображения картинок папка static/images/ должна содержать все файлы, перечисленные в словаре OUTFIT_IMAGES в app.py (например, casual_freezing_left.jpg, business_hot_right.jpg и т.д.). В репозитории эти изображения должны быть добавлены отдельно.

🔮 Перспективы развития
Добавление своих вещей — загрузка фотографий одежды пользователя и формирование образов только из имеющегося гардероба (потребуется база данных, например SQLite).

Слежка за трендами — интеграция с API модных медиа для учёта актуальных цветов и фасонов.

Выбор пола — фильтр для мужского / женского / универсального гардероба.

Постоянный хостинг — размещение на облачной платформе (например, Render, PythonAnywhere) для круглосуточного доступа.
