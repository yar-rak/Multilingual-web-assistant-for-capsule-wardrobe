## 📖 О проекте

**Smart Stylist** — это веб-приложение на Python/Flask, которое помогает решить ежедневную проблему «Что надеть?». Сервис автоматически определяет текущую погоду в любом городе мира, относит её к одной из пяти температурных зон и предлагает готовый капсульный образ для выбранного стиля.

Проект объединяет моду и информационные технологии (направление **FashionTech**) и создан в рамках исследовательской работы на Челябинском молодёжном интеллектуальном форуме «Шаг в будущее — Созвездие НТТМ» (секция 3.2 «Информационные технологии в науке, технике»).

### 🎯 Почему это полезно?

- **Экономия времени** — не нужно думать над образом каждое утро.
- **Комфорт** — рекомендации учитывают реальную температуру, чтобы вы не замёрзли и не перегрелись.
- **Доступность** — бесплатно, работает в браузере, не требует установки.
- **Мультиязычность** — интерфейс и рекомендации на русском, английском и французском языках.

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 🌍 **Погода в реальном времени** | Запрос к WeatherAPI по названию города |
| 🌡️ **5 погодных зон** | `freezing` (≤0°C), `cold` (1–10°C), `chilly` (11–17°C), `warm` (18–23°C), `hot` (≥24°C) |
| 👔 **3 стиля одежды** | Casual, Business Chic, Streetwear |
| 🌐 **Мультиязычность** | Полная локализация на RU / EN / FR |
| 🖼️ **Визуализация** | Две картинки с подобранным образом (слева и справа) |
| 🛡️ **Обработка ошибок** | Понятное сообщение, если город не найден или API недоступен |

## 🚀 Установка и запуск

### 1. Клонируйте репозиторий

```bash
git clone https://github.com/yar-rak/Multilingual-web-assistant-for-capsule-wardrobe.git
cd Multilingual-web-assistant-for-capsule-wardrobe
```

### 2. Установите зависимости

Рекомендуется использовать виртуальное окружение:

```bash
python -m venv venv
source venv/bin/activate      # для Linux/macOS
venv\Scripts\activate         # для Windows
```

Затем установите библиотеки:

```bash
pip install flask requests
```

### 3. Настройте API-ключ (опционально)

В файле `app.py` уже указан демонстрационный ключ WeatherAPI. Для стабильной работы рекомендуется заменить его на свой, полученный после регистрации на [weatherapi.com](https://www.weatherapi.com/). Ключ хранится в переменной `WEATHER_API_KEY`.

### 4. Запустите приложение

```bash
python app.py
```

### 5. Откройте в браузере

```text
http://127.0.0.1:5000
```

## 📖 Использование

1. Выберите язык интерфейса в выпадающем списке (переключение происходит автоматически).
2. Введите название города **латиницей** (например, `Moscow`, `Paris`, `London`).
3. Выберите желаемый стиль одежды.
4. Нажмите кнопку **«Сформировать капсулу»** (или аналог на выбранном языке).
5. Получите текущую температуру, описание погоды и подробный список рекомендованных вещей. По бокам отобразятся подобранные образы.

> 💡 **Примечание:** для корректного отображения картинок папка `static/images/` должна содержать все файлы, перечисленные в словаре `OUTFIT_IMAGES` в `app.py` (например, `casual_freezing_left.jpg`, `business_hot_right.jpg` и т.д.). В репозитории эти изображения должны быть добавлены отдельно.

## 🔮 Перспективы развития

- **Добавление своих вещей** — загрузка фотографий одежды пользователя и формирование образов только из имеющегося гардероба (потребуется база данных, например SQLite).
- **Слежка за трендами** — интеграция с API модных медиа для учёта актуальных цветов и фасонов.
- **Выбор пола** — фильтр для мужского / женского / универсального гардероба.
- **Постоянный хостинг** — размещение на облачной платформе (например, Render, PythonAnywhere) для круглосуточного доступа.
